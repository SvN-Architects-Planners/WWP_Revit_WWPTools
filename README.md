# WWPTools

WWPTools is now distributed as a pyRevit Git extension.

## Install or Update

1. Open pyRevit Extension Manager.
2. Add this Git repository URL:

   `https://github.com/WWP-Architects-Planners/WWP_Revit_WWPTools`

3. Install or update the extension from Extension Manager.
4. Restart Revit or reload pyRevit.

## Installer Transition

Version 1.5.0 is the final transition MSI release. New installs and future updates should use the pyRevit Git extension workflow above instead of downloading an MSI.

## Updates

Use pyRevit Extension Manager or the `Update WWPTools` command in the WWPTools ribbon. The update command requires the extension to be installed as a Git clone.
